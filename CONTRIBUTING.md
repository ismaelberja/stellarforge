# Contribution guide

This project is a supervised, iterative **scientific research** program. Do not publish new candidate-star classifications without explicit review of source identity, archive provenance, observation flags, period-window artefacts and alternative physical explanations.

All contributions must include:

1. A short research/engineering motivation tied to a specific roadmap phase.
2. Tests appropriate to the change; network access should be mocked for unit tests.
3. Explicit input catalogue citation and schema/selection logic when applicable.
4. Versioned scientific assumptions, known limitations and a research-log entry.
5. Transparent disclosure if substantial parts of code or interpretation were generated by AI tools.

Do not commit raw astronomical survey downloads or any unpublished collaborative ALMA/TFM data.
