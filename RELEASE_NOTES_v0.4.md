# StellarForge v0.4 — Technical research release (2026-11-04)

- **Real source metadata:** located pinned 532-member machine-readable Luhman (2023) adopted Taurus census at a public GitHub mirror; verified 467 unique Gaia source IDs, 65 absent IDs and all 13 named kinematic groups. Publisher-byte equality still pending.
- **Real positional subset:** deterministic, 24-member technical seed, source-line traceability, provenance and true-coordinate plot. It is **not** a final 12/12 disk-class science cohort.
- **ZTF worklist:** official API query plans for all 24 objects, none sent; positional and release matching not inferred.
- **Statistical engine:** uncertainty-aware magnitude features, weighted floating-mean Lomb–Scargle, sampling-window flags, seed-fixed white-noise permutation diagnostic and no physical classifications.
- **Numerical evaluation:** 72 **synthetic** injection/recovery trials at 5.271 d: 24/24 irregular high-signal, 24/24 seasonal gaps and 15/24 sparse low-signal. Two explicitly synthetic diagnostic figures.
- **Software:** version 0.4.0, new CLI commands, 109 tests passing, 24 query plans, full audit trail and research docs.
- **Open research:** source comparison with editor, disk-class validation, authentic ZTF photometry, proper-motion epoch matching, red-noise/aliases, literature benchmarking and any valid scientific result.
