# StellarForge v0.9 — Observational evidence

This directory is a **research-readiness artifact**, not a paper result.

- `TWO_STAR_OFFICIAL_IRSA_QUERY_PLAN.json` contains official IRSA URLs.
- `*_EVIDENCE_DOSSIER.json` documents per-target scientific gates and source provenance.
- `STELLARFORGE_V09_EVIDENCE_DASHBOARD.html` is an offline standalone dashboard.
- `RUN_SUMMARY.json` distinguishes network failures from no astronomical coverage.

Until response bytes, ZTF OIDs, Gaia cross-match and image checks are independently verified, **no Taurus ZTF photometry or physical detections are claimed**.
