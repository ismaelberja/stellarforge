This is an independent **target-identity** increment after the original external [PS1/ZTF reference-photometry pilot](R2_REAL_FTTAU_EXTERNAL_MAST_PS1_DR2_SOURCE_COLOR_RESULTS.md). ## Prospective fixed original-source data and exposures

- Exactly **four previously selected and image/mask-checked ZTF original full detector quadrant \`psfcat.fits\` files**, original exact historical FT Tau g/r field 1605 CCD15 Q3 and field 609 CCD8 Q4, same as original observational R2. Their original byte SHA-256 fingerprints **must** match the previously committed original four-image ledger, otherwise hard NO-GO. The two same-band cross-field pairs are 39 seconds apart; g is from **2019-11-19** and r from **2018-11-03**. No OID, exposure or observing epoch may be post-selected to improve a source alignment.
- Exactly **one Gaia DR3 five-parameter astrometry original TAP query by FT Tau's frozen exact source ID**, including full 5×5 formal covariance and RUWE. At each of four fixed original MJDs propagate the Gaia J2016.0 epoch position by proper motion, approximate annual **geocentric** parallax and full formal covariance using the project's existing propagation. No topocentric aberration, radial-velocity perspective acceleration, orbital motion or Gaia/non-Gaia systematics can be inferred from the formal covariance alone.
- Exactly **one independent original MAST Pan-STARRS1 DR2 mean-source cone** with precisely the *same frozen 720″ source query and column set* from the previous genuinely independent PS1 reference pilot. Require full valid original CSV source rows; if returned catalogue hash differs from previous original source response, explicitly flag the change instead of pretending an exact byte repeat. Do not use PS1 mean positions as epoch-propagated stars because original per-source PS1 mean epoch/individual proper motion is **not** available in this source request.

## New target-specific, astrometric tests and thresholds (prospective)

1. **Reference positions:** reuse the exact preregistered PS1 mean-source photometric/quality/crowding/target-exclusion filter and ZTF native PSF quality/720″/15″ FT-target-exclusion screens. To calibrate *descriptive* independent-catalogue geometric offsets, use only unique **ZTF1605–ZTF609–PS1 source triplets** satisfying the previous strict reciprocal 0.75″ and same PS1 source at ≤0.6″ from each native ZTF position. No reference is selected based on how well its photometric or astrometric residual happens to agree, and the target region is excluded from the reference median.
2. **Holdout:** for each same-band original pair and **each field**, estimate a field-specific local \`(ZTF native sky position − PS1 DR2 mean sky position)\` east/north median from a predetermined **PS1 objID-based training split** (as in prior external PS1 study); compare against **unseen source IDs**. Require ≥20 total triples, ≥10 train and ≥8 holdout, and flag the reference-offset crossmatch diagnostic as INTERNAL-GEOMETRY-PASS only if each heldout signed coordinate median is within **0.10″** and both robust coordinate dispersions ≤**0.15″**. This verifies catalogue alignment on reference sources only, **not** fully calibrated PS1 astrometric error models, epoch corrections or ZTF WCS.
3. **Four original science-target source candidates:** within a fixed **2″** radius around the respective Gaia 5-parameter predicted position at each original exposure MJD, report the two closest native original ZTF PSFcat source separations (and the number of native entries inside 2″). Mark a *provisional candidate* only if exactly one is within **0.6″**, the second nearest is **>1″** (or absent), and that first native source passes the exact original PSF \`flags/chi/sharp/SNR/flux/sigflux\` quality cut; **do not reassign or drop poor-looking OIDs**, and preserve each source independently.
4. **Reference-offset-adjusted target:** subtract the *training-reference* ZTF-minus-PS1 median east/north offset from each native target-minus-propagated-Gaia offset to get a **descriptive differential** two-survey target position. Do not call this a formally calibrated Gaia–ZTF WCS residual: PS1 and ZTF have different epochs, source proper motions, blend uncertainties and common field calibration biases.
5. **Two same-filter near-simultaneous field pairs:** compare the two independently inspected candidate positions, and the differential positions, for g and r separately. When one original source is unavailable, out of radius, quality-failed or crowded, report **UNRESOLVED** for that band and do not cherry-pick another exposure. Record baseline Gaia-predicted g-vs-r change across 2018/2019, but **not** any directly detected astrophysical proper motion: residual interyear field/passband systematics cannot be independently excluded by this pilot.
6. **Independent PS1 near-target ambiguity check:** examine *all* original MAST PS1 DR2 rows from the fixed cone (not just well-measured calibrators) within **3″** of the exact Gaia J2016.0 and/or selected epoch positions, including rows rejected by the catalogue photometric calibration cuts. Report number within 1″/3″ and the angular distance to the nearest **original PS1 mean-source position**, but do **not** claim source identity from static sky proximity because PS1 reference epoch/proper motion and unresolved/noncatalogued blends are not solved. The existing fixed MAST cone filter \`nDetections≥5\` means noncatalogued/low-detection sources may be missing; absence is not proof of isolated target.
7. No photometric variation, companion, disk, binarity, period, variability amplitude or representative Taurus fraction is inferred. Even four agreeing target native centroids and no detected PS1 neighbour **cannot prove** a unique astrophysical Gaia–ZTF physical match without fully independent epoch-corrected per-source astrometry, PSF deblending and source/literature authentication. Therefore record **zero confirmed physical target matches and zero merged ObjectID lightcurves**, and leave full science **R2 OPEN**.

## Failure and data rules

Fail closed for missing/oversized or changed original catalogue, missing Gaia five-parameter covariance, non-finite astrometry, missing per-source positions and underpowered source-reference heldout. Never reinterpret a service failure as astrophysical nondetection. Preserve **only derived counts, anonymized nearest-source source-level offsets, genuine SHA-256 source fingerprints, quality/status flags and explicitly labeled limitations**; raw Gaia/PS1/ZTF source rows, star IDs, source time-series, pixels and catalogues stay transient on the GitHub Actions runner.
