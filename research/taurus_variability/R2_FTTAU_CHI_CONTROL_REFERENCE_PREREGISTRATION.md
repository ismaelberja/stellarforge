# Taurus R2 — prospectively locked PSF-chi reference-cohort sensitivity audit

**12 November 2026: registered before accessing new original ZTF science products for this study.**

## Scientific objective and fixed inputs

An original ZTF PSF-fit source candidate associated positionally with the Gaia DR3 FT Tau source **149623711269425408** failed the existing **0.5 ≤ native PSF chi ≤ 1.5** cut in each of three preselected late-night exposures (merged PR #45); their chi values were 0.456 (g 1605), 0.424 (g 609), 0.383 (r 609). All three had accepted positive flux/sigflux, SNR, sharp, flag and image-mask diagnostics. This additional study asks whether other **independent native PSF catalogue sources within the same six original dated exposures** also exhibit chi below 0.5 when selected *without using their chi*. This is a **descriptive sensitivity diagnostic only**, not calibration of a universal chi threshold or a new source-identity proof.

- Original 24-star technical seed, all four ZTF ObjectIDs, fields/CCDs/quadrants and original four 2018/2019 image anchors are frozen. The new sample is exactly the **three already preselected early/late independent-night same-OID pairs** from PR #44 for g1605, g609 and r609 (six original full ZTF `psfcat.fits` catalogues); r1605 is a predeclared **excluded comparison stratum** because neither of its selected epochs failed.
- For each fixed pair, repeat the original four exact-ObjectID IRSA CSV request + Gaia DR3 exact-ID five-parameter query, and **reconstruct the same chronologically selected first and last non-anchor UTC nights** using existing functions. Check both selected MJDs and both SHA-256 original full native catalogues exactly against the permanent PR #44 derived original 8-epoch ledger. Do not use image fit outcomes for sample selection. On a mismatch, *fail closed* and report an integrity error. Differences in original IRSA metadata response bytes are flagged; they do not authorize changing the fixed observation selection.
- The original Gaia position is propagated to each observed MJD using existing J2016.0 proper motion and approximate geocentric annual parallax. Both FT Tau **original nearest** source candidate profiles are checked against the **unchanged** original PSF geometry and [0.5,1.5] chi gate. Earlier PR #44/45 decisions are never overridden.

## Fixed control-source selection **independent of chi**

Use exactly each full native PSF catalogue, with **no PS1 source crossmatching or assumption of independent physical star identity**. Define a local 15″–720″ radial annulus about epoch-propagated Gaia, with **≥3″ distance to every other native catalogue detection** (including bad-fit entries), SNR ≥20, positive source flux and positive flux uncertainty, abs(sharp) ≤0.5, nonnegative flags and no native BAD_MASK_BITS=6141. Require native positions/chi/SNR finite and count only chi≥0 (invalid chi rejected and counted separately). **Neither lower nor upper chi values influence cohort inclusion**, avoiding the circularity of a prior chi-gated reference set. Freeze an additional **SNR-matched** subset at source SNR/2 ≤ control SNR ≤ source SNR×2 (the original FT Tau nearest source determines SNR for that frame, not its chi). Do not use control-source IDs, original magnitudes, or raw photometric rows in outputs.

Per fixed image measure total independent-of-chi controls, count/fraction with chi <0.5, in [0.5,1.5] and >1.5, chi quantiles p10/p50/p90, and the target's percentile among controls. Report the same for SNR-matched controls. **Require ≥20 controls in a group** to label its descriptive distribution as adequate; otherwise label UNDERPOWERED and retain counts. No significance, hypothesis-testing p-values or formal PSF model covariance inferred from a convenience cohort. Early/late contrasts are descriptive only, no joint source match across epochs.

## Hard scientific boundaries

No replacement epochs, relaxed source-quality gate, new calibrated Gaia–ZTF identity, significant proper motion, physical variability or merged ZTF ObjectID lightcurve is permitted. Original 5/8 source candidate passes, 3/8 failures and 1/4 valid two-night candidate pair are not revised. Even if many independent reference sources have chi <0.5, interpretation is **the lower gate's sensitivity to the original native catalogue metric**, NOT evidence that the three failed source candidates should be accepted or that the instrument noise model is wrong. Conversely few low-chi controls does not prove the FT Tau failures indicate new astrophysics. Original source rows, FITS pixels and IDs stay ephemeral; save only derived counts/quantiles, source hashes, fixed metadata, explicit data-quality statuses, and limitations.

ZTF documentation describes chi as a PSF-fit residual-versus-expected-noise metric and supplies official psfcat as original science product: https://irsa.ipac.caltech.edu/data/ZTF/docs/ztf_explanatory_supplement.pdf ; https://irsa.ipac.caltech.edu/docs/program_interface/ztf_metadata.html .
